# 💼 Personal Portfolio

A modern, responsive portfolio website built with **React** and **Vite** to showcase my skills, projects, experience, and contact information. Designed with a clean UI, smooth animations, and a mobile-first approach to provide an engaging user experience.

## 🌐 Live Demo

**Live Website:**
https://hardik0604.github.io/Portfolio/

---

## ✨ Features

* 👋 Professional landing page with an introduction
* 👨‍💻 About Me section
* 🛠️ Skills showcase
* 📂 Featured projects with live demos and source code
* 💼 Work experience timeline
* 📱 Fully responsive across all devices
* 🎨 Modern UI with smooth animations
* 📧 Contact section for easy communication
* ⚡ Fast performance powered by Vite

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/hardik0604/Portfolio.git
```

Navigate to the project directory:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

---

## 🚀 Build for Production

Build the project:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
